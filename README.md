# ☕ Coffee Website

A simple and visually appealing coffee-themed website built using HTML, CSS, and JavaScript. This project is designed to showcase the design and layout skills suitable for a café or coffee shop brand.

🌟 Features
Modern Homepage Design – Eye-catching landing page with stylish background and typography.

Multi-Page Navigation – Easily navigate between menu, drinks, login, and more.

Responsive Layout – Optimized for mobile, tablet, and desktop screens.

Dedicated Menu Pages – Separate pages for Beverages, Fast Food, and Best Offers.

Interactive Order Form – Place and customize orders directly from the website.

Login Interface – Clean login page layout for future user authentication.

Image-Rich Interface – Visually appealing with lots of product and ambience images.

Category-Based CSS Styling – Each section styled with its own CSS file for modular design.

## 🛠️ Technologies Used

- **HTML5** – Structure of the web pages
- **CSS3** – Styling and layout
- **JavaScript** – Interactive features and functionality
